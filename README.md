  ထင်းနေမယ်၊ မြှားက လှည့်သွားမယ်။
- **အစမှာ ပထမ မေးခွန်း ၁ ခု ဖွင့်ထားတယ်** — ကျန်တာတွေ ပိတ်ထားတယ်။

## စမ်းနည်း

1. /support ဖွင့် → FAQ မှာ မေးခွန်း ၆ ခု ပဲ ပေါ်ရမယ် (အဖြေတွေ မပေါ်ဘူး) —
   ပထမ ၁ ခုပဲ အဖြေ ပွင့်နေရမယ်။
2. မေးခွန်း တစ်ခုနှိပ် → အဖြေ ချောချောမွေ့မွေ့ ပွင့်လာရမယ်၊
   နံပါတ် Badge နဲ့ မြှား လှည့်သွားရမယ်။
3. နောက် မေးခွန်း တစ်ခုနှိပ် → အရင်ဟာ ပိတ်ပြီး အသစ်ဟာ ပွင့်ရမယ်။
4. ဖွင့်ထားတဲ့ မေးခွန်းကို ထပ်နှိပ် → ပိတ်သွားရမယ်။
